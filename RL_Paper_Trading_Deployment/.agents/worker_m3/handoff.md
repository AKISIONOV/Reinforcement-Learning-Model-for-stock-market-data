## 2. Logic Chain
- **Data Ingestion & Error Handling**: Designed `load_trade_log()` to check for `logs/paper_trade_log.csv`. If missing, the app halts with a clear user warning instructing them to run `python trade_executor.py` first.
- **Sidebar & Controls**: Added path selector, refresh data button (`st.rerun()`), execution mode badge (MOCK vs LIVE ALPACA), and strategy summary overview.
- **Header Metric Cards**: Computed 5 top-level metrics using `st.metric`:
  - Portfolio Net Worth ($) with dollar delta vs initial $1M.
  - Total Return (%) with delta.
  - Daily Return (%) with DoD delta.
  - Current Market Regime (e.g. Neutral / Bullish Low-Vol / Bearish High-Vol).
  - Execution Mode (MOCK vs LIVE).
- **Tab 1 (Portfolio Performance)**: Plotted Plotly interactive time-series line chart for Portfolio Net Worth vs $1,000,000 baseline, color-coded daily returns bar chart (green for profit, red for loss), and drawdown area curve over time.
- **Tab 2 (Current Asset Allocations)**: Derived net share holdings and current prices from trade log entries. Built donut chart of asset weights across DJIA equities + Cash, bar chart comparison, and formatted holdings data table.
- **Tab 3 (Market Regimes & Analytics)**: Constructed pie chart of time spent in each HMM regime state, regime breakdown table, and regime-highlighted portfolio trajectory scatter line chart.
- **Tab 4 (Execution Logs & Exports)**: Created interactive data table of recorded trade logs (`BUY`, `SELL`, `SNAPSHOT`) with Action Type, Ticker, and keyword search filters, plus a CSV download button.

## 3. Caveats
- The dashboard is designed to read `logs/paper_trade_log.csv` generated by `trade_executor.py`. If `trade_executor.py` is executed for additional steps, clicking "Refresh Data" in the sidebar updates all charts and metrics instantly.
