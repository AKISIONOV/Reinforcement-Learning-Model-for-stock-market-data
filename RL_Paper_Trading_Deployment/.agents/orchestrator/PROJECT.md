# Project: RL Paper Trading Deployment

## Architecture
- **Data Ingestion Module**: Fetches live/recent market OHLCV data for 28 DJIA equities using `yfinance`.
- **Feature & Regime Engine**: Computes 17 technical indicators + 3 HMM market regime probabilities, matching `data_pipeline.py` & `custom_env.py`.
- **Observation State Builder**: Constructs the exact 567-dimensional state vector required by `optimal_trading_model.zip`.
- **Model Inference Engine**: Loads `optimal_trading_model.zip` (SB3 PPO), feeds 567-dim state, and computes continuous action vector (-1.0 to 1.0) -> converted to target portfolio weights.
- **Execution Manager**: Dual-mode execution engine:
  - **Alpaca Trading API Mode**: Executed via Alpaca SDK when valid credentials exist in `.env`.
  - **Mock Execution Mode**: Automatically triggered when credentials are missing; simulates order execution with 10 bps transaction fees and logs trades/portfolio trajectory to `logs/paper_trade_log.csv`.
- **Streamlit Web Dashboard**: Interactive web app (`dashboard.py`) reading `logs/paper_trade_log.csv` and displaying Net Worth timeseries, P&L metrics, Asset Allocation donut chart, and Market Regime distributions.
- **Documentation & Setup**: `secrets_guide.md` providing step-by-step setup for free Alpaca paper trading API keys.

## Code Layout
- `trade_executor.py`: Main paper trading execution script containing data fetching, state assembly, model inference, and execution (Alpaca / Mock).
- `dashboard.py`: Streamlit web visualization app.
- `secrets_guide.md`: Comprehensive guide for obtaining and configuring Alpaca paper trading API credentials.
- `logs/paper_trade_log.csv`: Local trade and portfolio history CSV output generated by Mock Execution Mode / Alpaca execution.
- `.env.example`: Template file for API keys environment configuration.

## Interface Contracts
- **State Vector Shape**: `(567,)` float32 numpy array.
  - Cash norm (1)
  - Shares scaled (28)
  - Current prices (28)
  - Tech features (28 assets × 17 features = 476)
  - Market regime probabilities (3)
  - Risk state (3: drawdown, peak_net_worth_scaled, downside_vol)
  - Previous actions (28)
- **Trade Log CSV Format**:
  - `timestamp`: ISO-8601 string / date
  - `action`: BUY / SELL / HOLD / REBALANCE
  - `asset`: Ticker symbol
  - `shares`: Quantity traded
  - `price`: Execution price
  - `transaction_cost`: 0.001 (10 bps fee)
  - `portfolio_net_worth`: Total portfolio dollar value
  - `cash_balance`: Remaining cash balance
  - `market_regime`: State 0 / 1 / 2 (or Bullish / Neutral / Bearish)
